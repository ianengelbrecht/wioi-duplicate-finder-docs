### Nouveaux champs pour islandGroup et island

Ce sont des champs Darwin Core pour enregistrer les groupes d'îles (`islandGroup`) et les îles (`island`). Utilisez-les uniquement si nécessaire et si cette information n'est pas déjà saisie dans le pays ou dans un autre champ plus approprié.

Par exemple, si le pays est Maurice, vous n'avez pas besoin de saisir « Maurice » comme île. Pour les Seychelles (qui sont à la fois un pays et un groupe d'îles), saisissez « Seychelles » comme pays et laissez le groupe d'îles vide, mais vous voudrez probablement saisir le nom de l'île spécifique où le spécimen a été récolté.

### Alerte pour les noms de taxons non présents dans le WCVP

Le chercheur de doublons utilise le WCVP en arrière-plan pour les noms de taxons, mais les fiches de référence du GBIF peuvent utiliser des noms qui n'apparaissent pas dans le WCVP. Si vous sélectionnez une fiche en doublon à saisir, vous verrez désormais un message d'avertissement si le nom de taxon associé n'est pas présent dans la liste de référence du WCVP. Vous pouvez bien sûr rechercher le nom dans la base de données pour voir s'il y est représenté légèrement différemment, ou le laisser tel quel.

De plus, si vous saisissez manuellement un nouveau spécimen, vous pouvez tapez le nom du taxon tel qu'il apparaît sur l'étiquette, même si ce nom ne figure pas dans la liste déroulante. Cela est utile pour les noms *ined.* (ineditus), par exemple (bien qu'il convienne de se demander si les noms non publiés doivent être saisis dans nos bases de données, étant donné que la plupart des herbiers publient désormais ces jeux de données en ligne et risquent de publier accidentellement des noms non publiés avant l'auteur).
