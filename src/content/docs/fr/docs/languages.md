L'application est localisée pour prendre en charge plusieurs langues parlées dans les îles du
sud-ouest de l'océan Indien et sur le continent africain.

---

## Changer la langue de l'interface

Vous pouvez changer la langue de l'interface utilisateur à tout moment.

1. Repérez les boutons de langue dans le coin supérieur droit de l'en-tête de l'application.
2. Sélectionnez votre langue préférée :
   - **EN** : Anglais (English)
   - **FR** : Français (Français)
   - **PT** : Portugais (Português)
   - **MG** : Malgache (Malagasy)
3. Les éléments de l'interface, les étiquettes, les espaces réservés et les avertissements de
   validation seront mis à jour immédiatement. Le système mémorise également votre préférence pour
   la prochaine fois que vous ouvrirez l'application.

![Sélecteurs de langue dans l'en-tête](/wioi-duplicate-finder-docs/language-selector.png)

---

## Retours sur la traduction et contributions

Si vous trouvez des traductions incorrectes, des formulations maladroites ou des étiquettes non
traduites en français, portugais ou malgache :

1. Veuillez ouvrir un ticket de retour sur la traduction sur notre
   [page des tickets du dépôt GitHub](https://github.com/ianengelbrecht/wioi-duplicate-finder/issues).
2. Spécifiez le texte actuel de l'étiquette, la traduction recommandée et le code de langue (FR, PT
   ou MG).
3. Si vous avez un grand nombre de suggestions, veuillez également nous contacter via GitHub pour
   nous faire savoir que vous souhaitez aider avec ces traductions. Nous pourrons vous fournir les
   tableaux de traduction nécessaires et intégrer ces mises à jour dans l'application.
