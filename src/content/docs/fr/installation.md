## Installation

Pour installer la recherche de doublons (Duplicate Finder), vous devrez télécharger deux fichiers : l'installateur de l'application et un fichier de base de données avec lequel l'application fonctionnera. Les liens de téléchargement se trouvent ci-dessous ; choisissez la base de données appropriée pour votre région. 

#### Étape 1 : Télécharger l'installateur de l'application

[Installateur de l'application](https://github.com/ianengelbrecht/wioi-duplicate-finder/releases/download/app-v0.6.2/duplicate-finder_0.6.2_x64-setup.exe)

#### Étape 2 : Sélectionner et télécharger une base de données pour votre région

- [Îles de l'océan Indien occidental](https://github.com/ianengelbrecht/wioi-duplicate-finder/releases/download/app-v0.6.0/wioi-reference-db-wioi-v0.6.0.zip)
- Afrique australe (bientôt disponible...)

La base de données est zippée, vous devez donc la décompresser et déplacer le fichier `.db` vers un emplacement approprié sur votre ordinateur avant de commencer à travailler avec (par exemple, votre dossier Documents). 

Double-cliquez ensuite sur l'installateur de l'application pour lancer le processus d'installation. Un écran bleu indiquant « Windows a protégé votre ordinateur » s'affichera. Cliquez sur « Informations complémentaires » (More Info), puis sur « Exécuter quand même » (Run Anyway). L'installateur s'exécutera ; vous pouvez accepter toutes les options par défaut lors de l'installation.

![Écran bleu d'installation](/wioi-duplicate-finder-docs/blue-screen.png)
Cliquez sur « Informations complémentaires » (More Info), puis sur « Exécuter quand même » (Run Anyway)

![Installateur](/wioi-duplicate-finder-docs/installer.png)
Cliquez sur Suivant (Next) tout au long du processus d'installation pour sélectionner les options par défaut. 

Lorsque vous lancez l'application pour la première fois, elle vous demandera où se trouve la base de données. Naviguez vers et sélectionnez le fichier de base de données que vous avez téléchargé et décompressé. Vous ne devez faire cela que la première fois que l'application s'exécute (sauf si vous déplacez à nouveau le fichier de base de données par la suite).  

Notez que lorsque vous lancez l'installateur, vous obtiendrez un écran bleu vous demandant si vous faites confiance à l'éditeur pour l'installation.

## Mises à jour de l'application

Une fois installée, l'application vérifie automatiquement les mises à jour à chaque démarrage (cela nécessite une connexion Internet). Si elle trouve une mise à jour, elle affichera un bouton à côté du sélecteur de langue vous proposant de télécharger et d'installer la mise à jour. La mise à jour s'effectue automatiquement et l'application redémarrera une fois celle-ci terminée.
