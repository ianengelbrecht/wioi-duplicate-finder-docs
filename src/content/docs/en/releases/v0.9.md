## v0.9.1

- Added source field to export to track whether records are entered from duplicates, from JSON, or manually.
- Moved locality lookup to a separate dialog as it was interfering with typing on the main form.
- Added sorting on various fields to the captured records table.
- Added a warning if a record with the same barcode is already captured (to prevent accidental duplication).
- Added a setting for expected date format for the collection, for better verbatim date parsing.
- Other minor fixes and UI improvements.

## v0.9.0

### Paste Darwin Core data into the capture form

To support workflows that include the use of AI to capture data from an image of a specimen label,
the option is added to paste a JSON object containing Darwin Core data into the data capture form
directly. The intention is that a user would post their image to their favourite LLM and request
Darwin Core data with appropriate fields, in JSON format, and then copy/paste the result back into
the tool. By doing so the tool can be integrated into workflows using AI.

### App start up time

Attempted to speed up the startup time for the app (during the database normalization phase).

### Other

Only minor UI updates and fixes.
