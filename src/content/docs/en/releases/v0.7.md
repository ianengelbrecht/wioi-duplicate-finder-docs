### New fields for islandGroup and island

These are Darwin Core fields for recording island groups (`islandGroup`) and islands (`island`).
Only use these if needed, and only if this information is not already captured by the country or
another more appropriate field.

For example, if the country is Mauritius, you do not need to record 'Mauritius' as the island. For
the Seychelles (which is both a country and an island group), record 'Seychelles' as the country and
leave 'Island Group' empty, but you will likely want to record the name of the specific island where
the specimen was collected.

![Island Group and Island fields](/wioi-duplicate-finder-docs/releases-0.7.0-island-fields.png)

### Alert for taxon names not in WCVP

The Duplicate Finder uses WCVP in the background for taxon names, but reference records from GBIF
might use names that do not appear in WCVP. If you select a duplicate record to capture, you will
now see a warning message if the associated taxon name is not in the WCVP checklist. You can search
for the name in the database to see if it is represented slightly differently, or leave it as is.

Additionally, when capturing a new specimen manually, you can type the taxon name exactly as it
appears on the label, even if it is not in the dropdown list. This is useful for _ined._ (ineditus)
names, for example (though it is worth considering whether unpublished names should be captured,
since most herbaria now publish their datasets online and could accidentally publish unpublished
names before the authors do).
