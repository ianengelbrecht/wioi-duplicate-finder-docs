## V0.8.0

### Better collector and determiner lookups

Because the application uses raw GBIF reference data to populate these dropdown lists, we previously
saw many values with incorrect or unwanted formatting. Filters have now been added to show only
properly formatted values. There is also a new setting to choose whether to include full stops in
initials. Additionally, values you add manually are prioritized at the top of the list for easier
access.

### Search rule updates

Search rules have been improved. For example, you can now search with a collector number and date
without needing a collector name.

### Country-specific locality examples

Placeholders in the locality fields are now country-specific to make it clearer how those fields
should be used. There is an accompanying country setting that you need to configure for this to
work.

### Added user management

Users now record their name and initials so this information is available where needed in the app.
The first user who signs up is automatically made an admin, allowing them to see all sessions (in
case an admin needs to export another user's dataset) and promote other users to admin. Users are
managed from the home page.

### Locality lookups

When adding a locality to a new record, selecting an item in the dropdown now also populates the
country, admin (province/state), and coordinates fields.

### Islands fields now optional

Including the `islandGroup` and `island` fields is now optional via a setting.

### Fixed the taxon name lookup

The taxon name lookup has been refined so that `Ad dig` only returns names like `Adansonia digitata`
and **not** also `Digitaria digitiformis`. This actually required quite extensive code changes!
