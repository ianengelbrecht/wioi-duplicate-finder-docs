The application is localized to support multiple languages spoken in the Western Indian Ocean
islands and across the African continent.

---

## Changing the UI Language

You can change the language of the user interface at any time.

1. Locate the language buttons in the top-right corner of the application header.
2. Select your preferred language:
   - **EN**: English
   - **FR**: French (Français)
   - **PT**: Portuguese (Português)
   - **MG**: Malagasy (Malagasy)
3. The interface elements, labels, place holders, and validation warnings will update immediately.
   The system also remembers your preference the next time you open the app.

![Language Selectors in Header](/wioi-duplicate-finder-docs/language-selector.png)

## Translation Feedback & Contributions

If you find incorrect translations, awkward phrasing, or untranslated labels in French, Portuguese,
or Malagasy:

1. Please open a translation feedback issue on our
   [GitHub repository issues page](https://github.com/ianengelbrecht/wioi-duplicate-finder/issues).
2. Specify the current label text, the recommended translation, and the language code (FR, PT, or
   MG).
3. If you have a large number of suggestions, please reach out through Github also, and let us know
   you'd like to help with those translations. We can provide you with the necessary translation
   tables and make those updates back into the application.
