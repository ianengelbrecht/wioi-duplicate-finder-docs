## Installation

To install the Duplicate Finder you will need to download two files, the application installer and a database file for the application will work with. Download links are below, choose the appropriate database for your region. 

#### Step 1: Download the application installer

[Application installer](https://github.com/ianengelbrecht/wioi-duplicate-finder/releases/download/app-v0.6.3/duplicate-finder_0.6.3_x64-setup.exe)

#### Step 2: Select and download a database for your region

- [West Indian Ocean Islands](https://github.com/ianengelbrecht/wioi-duplicate-finder/releases/download/app-v0.6.0/wioi-reference-db-wioi-v0.6.0.zip)
- Southern Africa (coming soon...)

The database is zipped, so you need to unzip it and move the .db file to a suitable location on your computer before you start to work with it (e.g. your Documents folder) . 

Then double click the application installer to start the installation process. It will show you a blue screen saying Windows protected your PC. Here you can click on More Info, and then Install Anyway. The installer will run, you can accept all default options during the installation.

![Installation Blue Screen](/wioi-duplicate-finder-docs/blue-screen.png)
Click on More Info, and then on Run Anyway

![Installer](/wioi-duplicate-finder-docs/installer.png)
Click Next all the way through with the installer to select default options. 

When you run the app for the first time it will ask you where the database is. Navigate to and select that database file that you downloaded and unzipped. You only need to do this the first time the application runs (unless you move the database file again afterwards).  

Note that when you run the installer you will get a blue screen asking if you trust the publisher to install.

## App updates

Once installed, the app automatically checks for updates every time you start it (this needs an internet connection). If it finds an update it will display a button next to the language selector offering for you to download and install the update. The update happens automatically and the app will restart when it is completed.
