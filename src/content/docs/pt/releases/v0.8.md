---
title: v0.8 Atualizações e funcionalidades
---

### Melhores buscas de coletores e determinadores

Como o aplicativo usa dados de referência brutos do GBIF para preencher essas listas suspensas,
anteriormente víamos muitos valores com formatação incorreta ou indesejada. Filtros foram
adicionados para exibir apenas os valores formatados corretamente. Há também uma nova configuração
para escolher se deseja incluir pontos nas iniciais. Além disso, os valores adicionados manualmente
por você têm prioridade no topo da lista para facilitar o acesso.

### Atualizações nas regras de busca

As regras de busca foram aprimoradas. Por exemplo, agora você pode pesquisar com um número de
coletor e uma data sem precisar do nome do coletor.

### Exemplos de localidade específicos por país

Os textos de exemplo (placeholders) nos campos de localidade agora são específicos do país para
tornar mais claro como esses campos devem ser utilizados. Há uma configuração de país correspondente
que você precisa definir para que isso funcione.

### Adicionado gerenciamento de usuários

Os usuários agora registram seus nomes e iniciais para que essa informação esteja disponível onde
for necessário no aplicativo. O primeiro usuário a se cadastrar é automaticamente definido como
administrador, permitindo-lhe visualizar todas as sessões (caso um administrador precise exportar o
conjunto de dados de outro usuário) e promover outros usuários a administrador. Os usuários são
gerenciados a partir da página inicial.

### Buscas de localidade

Ao adicionar uma localidade a um novo registro, a seleção de um item na lista suspensa agora também
preenche os campos de país, divisão administrativa (província/estado) e coordenadas.

### Campos de ilhas agora opcionais

A inclusão dos campos `islandGroup` e `island` agora é opcional por meio de uma configuração.

### Corrigida a busca de nome do táxon

A busca de nome de táxon foi refinada para que `Ad dig` retorne apenas nomes como
`Adansonia digitata` e **não** também `Digitaria digitiformis`. Isso exigiu alterações bastante
extensas no código!
