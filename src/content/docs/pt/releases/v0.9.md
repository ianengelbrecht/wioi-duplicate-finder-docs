## v0.9.1

- Adicionado o campo de origem na exportação para rastrear se os registros foram inseridos a partir de duplicatas, de JSON ou manualmente.
- A busca de localidade foi movida para uma caixa de diálogo separada, pois estava interferindo na digitação no formulário principal.
- Adicionada ordenação em vários campos na tabela de registros capturados.
- Exibição de um aviso caso um registro com o mesmo código de barras já tenha sido capturado (para evitar duplicações acidentais).
- Adicionada uma configuração para o formato de data esperado da coleção, para melhor análise da data verbatim.
- Outras correções menores e melhorias na interface do usuário.

## v0.9.0

### Colar dados do Darwin Core no formulário de captura

Para suportar fluxos de trabalho que incluem o uso de IA para capturar dados a partir de uma imagem
da etiqueta de um espécime, foi adicionada a opção de colar um objeto JSON contendo dados do Darwin
Core diretamente no formulário de captura de dados. A intenção é que o usuário envie sua imagem para
seu LLM favorito, solicite os dados do Darwin Core com os campos apropriados em formato JSON, e
depois copie/cole o resultado de volta na ferramenta. Dessa forma, a ferramenta pode ser integrada a
fluxos de trabalho que utilizam IA.

### Tempo de arranque da aplicação

Tentativa de acelerar o tempo de inicialização da aplicação (durante a fase de normalização da base de dados).

### Outro

Apenas atualizações menores na interface do usuário e correções de bugs.
