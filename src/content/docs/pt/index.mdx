<CardGrid stagger>

	</Card>

	</Card>
	<Card title="Gerenciamento de Sessões" icon="list-format">

	</Card>

		Exporte os registros de espécimes capturados da sua sessão para um formato CSV padrão para importação no seu sistema de gerenciamento de herbário.
